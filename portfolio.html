🚗 Car Selling Price Prediction

A machine learning project to predict the selling price of a car based on features like model, year, km driven, and fuel type. Built using Python and various ML models with a focus on practical applications and performance.

🔍 Project Highlights

  • Exploratory Data Analysis (EDA)
  • Feature Engineering and Data Preprocessing
  • Model Comparison: Linear Regression, Random Forest, XGBoost
  • Achieved R² score of ~0.88
  • Model saved using joblib for deployment

📈 Model Performance

Model R² Score
Linear Regression 0.78
Random Forest 0.86
XGBoost 0.88

📁 How to Run

  1. Clone the repo: git clone https://github.com/Ishikkaa/Car-Selling-Price-Prediction.git
  2. Navigate to the project folder
  3. Install dependencies: pip install -r requirements.txt
  4. Open Car Price Prediction.ipynb in Jupyter Notebook
